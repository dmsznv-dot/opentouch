# Как запустить OpenTouch на Mac

## Один раз: подготовка

1. Установи **Node.js 22**: скачай установщик с nodejs.org (кнопка LTS), запусти и пройди установку.
2. Открой **Терминал** (Spotlight → «Терминал»).
3. Вставь и нажми Enter:

```bash
git clone -b claude/mapper-v1-spec https://github.com/dmsznv-dot/opentouch ~/opentouch && cd ~/opentouch && npm install
```

Если macOS предложит установить «Command Line Tools» (это нужно для git), согласись и потом повтори команду.

## Запуск программы

```bash
cd ~/opentouch && npm run dev
```

- Откроется окно редактора.
- Если проектор подключён, окно вывода само откроется на нём на весь экран.
- Без проектора можно смотреть вывод в обычном окне:

```bash
cd ~/opentouch && OPENTOUCH_FAKE_DISPLAY=1 npm run dev
```

## Первые шаги в программе

1. Слева **＋** у Surfaces — добавить поверхность.
2. **＋ Video** — выбрать видеофайл (или перетащить файл в окно).
3. Тянуть углы мышью, стрелки — точная подгонка, **T** — тестовая сетка.
4. **Tab** — переключение Edit / Show.
5. **⌘S** — сохранить проект.

Все клавиши — в [README](../README.md#горячие-клавиши).

## Обновить до последней версии

```bash
cd ~/opentouch && git pull && npm install
```

## Если хочешь помочь проверить (необязательно)

Автотесты самого приложения:

```bash
cd ~/opentouch && npm run test:e2e
```

Результат (или ошибку целиком) пришли в чат. Подробный ручной чек-лист с проектором — [manual-test-checklist.md](manual-test-checklist.md).
