# Как установить OpenTouch на Mac

## 1. Скачать

Страница загрузки: **https://github.com/dmsznv-dot/opentouch/releases/latest**

- Mac на Apple Silicon (M1, M2, M3, M4) — **OpenTouch-arm64.dmg**
- Mac на Intel — **OpenTouch-x64.dmg**

Не знаешь, какой у тебя? Меню  → «Об этом Mac» → строка «Чип» (Apple M…) или «Процессор» (Intel).

## 2. Установить

Открой скачанный `.dmg` и перетащи **OpenTouch** в папку **Applications**.

## 3. Первый запуск

Для предварительных сборок с пометкой Preview может понадобиться один раз разрешить запуск в macOS:

1. Запусти OpenTouch из Applications. Появится окно «не удаётся проверить разработчика» — нажми **Готово** / **OK**.
2. Открой **Системные настройки → Конфиденциальность и безопасность**, пролистай вниз, у строки про OpenTouch нажми **Всё равно открыть** и подтверди паролем.

Если macOS пишет, что приложение **«повреждено»**, открой Терминал и выполни одну команду, затем запусти программу снова:

```bash
xattr -dr com.apple.quarantine /Applications/OpenTouch.app
```

## 4. Первые шаги

1. Подключи проектор (HDMI). Окно вывода само откроется на нём на весь экран.
2. Слева **＋** у Surfaces — добавить поверхность.
3. **＋ Video** — выбрать видеофайл (или перетащить файл в окно).
4. Тянуть углы мышью, стрелки — точная подгонка, **T** — тестовая сетка.
5. **Tab** — переключение Edit / Show. **⌘S** — сохранить проект.

Все клавиши — в [README](../README.md#горячие-клавиши). Ручной чек-лист с проектором — [manual-test-checklist.md](manual-test-checklist.md).

## Новая версия

Первую подписанную сборку установи из DMG в Applications. Затем нажми **Updates** в OpenTouch. Приложение проверит наличие новой версии и скачает её. Сохрани проект и нажми **Install and restart**.

Сборки Preview доступны на [странице релизов](https://github.com/dmsznv-dot/opentouch/releases). Для них обновления внутри приложения недоступны.

## Сиквенсер и эффекты

1. Выбери пустую поверхность и нажми **＋ Sequence**. Для существующей поверхности выбери последовательность в поле **Source**.
2. Нажми **＋ Video clips** или **＋ Audio clips** либо перетащи файлы на шкалу времени. Новые файлы добавляются в конец соответствующей дорожки.
3. Перетаскивай клипы по шкале. Выбери клип, чтобы изменить его положение, начало внутри исходного файла и длительность. Видеоклипы на одной дорожке перекрываются по времени начала. Отдельная аудиодорожка играет вместе со звуком текущего видео.
4. В инспекторе источника добавляй и переставляй **Effect nodes**. Например, **Displace → ASCII Art** искажает видео и переводит его в символы. **Particles** можно добавить в последовательность с одной аудиодорожкой. Размер и движение частиц реагируют на бас, а **Audio Pulse** увеличивает масштаб входного изображения под бас.
5. В инспекторе поверхности включи **Crop to fill**. В режиме **Input** будет видна область обрезки. Для изменения исходной области выключи галочку, подвинь рамку и включи её снова.

## Публикация подписанных сборок

Для обновлений внутри приложения настрой в GitHub Actions секреты `MAC_CSC_LINK` и `MAC_CSC_KEY_PASSWORD` с сертификатом Developer ID Application и секреты для нотаризации `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID`. Workflow публикует DMG, ZIP и манифест отдельно для Apple Silicon и Intel. Все подписанные версии должны использовать одну команду Apple Developer и один идентификатор приложения.

## Для разработки (необязательно)

Нужен Node.js 22 (nodejs.org, кнопка LTS). В Терминале:

```bash
git clone -b claude/mapper-v1-spec https://github.com/dmsznv-dot/opentouch ~/opentouch && cd ~/opentouch && npm install
```

Запуск из исходников (первый раз один раз скачает Electron, ~100 МБ):

```bash
cd ~/opentouch && npm run dev
```

Автотесты приложения (идут по одному, 1–2 минуты):

```bash
cd ~/opentouch && npm run test:e2e
```
