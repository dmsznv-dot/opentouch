# Как установить OpenTouch на Mac

## 1. Скачать

Страница загрузки: **https://github.com/dmsznv-dot/opentouch/releases/latest**

- Mac на Apple Silicon (M1, M2, M3, M4) — **OpenTouch-arm64.dmg**
- Mac на Intel — **OpenTouch-x64.dmg**

Не знаешь, какой у тебя? Меню  → «Об этом Mac» → строка «Чип» (Apple M…) или «Процессор» (Intel).

## 2. Установить

Открой скачанный `.dmg` и перетащи **OpenTouch** в папку **Applications**.

## 3. Первый запуск

Программа не подписана сертификатом Apple, поэтому macOS при первом запуске её заблокирует. Это нужно разрешить один раз:

1. Запусти OpenTouch из Applications. Появится окно «не удаётся проверить разработчика» — нажми **Готово** / **OK**.
2. Открой **Системные настройки → Конфиденциальность и безопасность**, пролистай вниз, у строки про OpenTouch нажми **Всё равно открыть** и подтверди паролем.

Если macOS пишет, что приложение **«повреждено»**, открой Терминал и выполни одну команду, затем запусти программу снова:

```bash
xattr -dr com.apple.quarantine /Applications/OpenTouch.app
```

## 4. Первые шаги

1. Подключи проектор (HDMI). Окно вывода само откроется на нём на весь экран.
2. Слева **＋** у Surfaces — добавить поверхность.
3. **＋ Video** — выбрать видеофайл (или перетащить файл в окно).
4. Тянуть углы мышью, стрелки — точная подгонка, **T** — тестовая сетка.
5. **Tab** — переключение Edit / Show. **⌘S** — сохранить проект.

Все клавиши — в [README](../README.md#горячие-клавиши). Ручной чек-лист с проектором — [manual-test-checklist.md](manual-test-checklist.md).

## Новая версия

Каждое обновление кода автоматически собирает новый `.dmg` на той же странице загрузки. Скачай и замени приложение в Applications.

## Для разработки (необязательно)

Нужен Node.js 22 (nodejs.org, кнопка LTS). В Терминале:

```bash
git clone -b claude/mapper-v1-spec https://github.com/dmsznv-dot/opentouch ~/opentouch && cd ~/opentouch && npm install
```

Запуск из исходников (первый раз один раз скачает Electron, ~100 МБ):

```bash
cd ~/opentouch && npm run dev
```

Автотесты приложения (идут по одному, 1–2 минуты):

```bash
cd ~/opentouch && npm run test:e2e
```
