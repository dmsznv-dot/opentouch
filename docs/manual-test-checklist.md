# OpenTouch Mapper v1 — ручной чек-лист на реальном проекторе

Перед прогоном: `npm run build && npm start` (или собранное приложение). Проектор подключён по HDMI, keystone в проекторе выключен, комната тёмная.

## Чёрный вне поверхностей
- [ ] При открытии окна вывода нет белой вспышки (смотреть на стену, не на экран ноутбука).
- [ ] После перезапуска приложения (⌘Q → запуск) нет белой вспышки.
- [ ] После отключения и подключения HDMI нет белой вспышки, вывод возвращается сам в прежнем режиме.
- [ ] Вне поверхностей на стене нет «серого прямоугольника» от программы: видна только собственная засветка проектора на чёрном (сравнить с выключенным выводом — кнопка Output).
- [ ] В Show нет курсора, контуров и ручек; в Edit они видны.

## Калибровка
- [ ] Углы quad тянутся мышью, стрелки двигают на 1 px, Shift+стрелки на 10 px (видно на стене).
- [ ] Тест-сетка (T) ложится на объект без «излома» по диагонали.
- [ ] Сетка 4×4 (инспектор → Grid On), режим Smooth: изгиб плавный; Bezier: ручки тянутся.
- [ ] Две соседние поверхности: угол прилипает к углу соседа (S выключает прилипание).
- [ ] Маска (M): контур обводит окно на стене, вне маски чёрное; Feather даёт мягкий край.

## Видео
- [ ] H.264 1080p играет плавно, loop без чёрного кадра на стыке.
- [ ] HEVC (`tests/fixtures/bars-hevc.mp4` после `scripts/make-fixtures.sh`): играет / не играет — записать в spec §9.
- [ ] Две поверхности с одним видео и разными Input-вырезками синхронны.
- [ ] Удалённый с диска файл → источник красный, Relink, после выбора файла играет.

## Надёжность
- [ ] Autostart включён → перезагрузка Mac → проект открывается в Show на проекторе без кликов.
- [ ] Принудительный краш renderer (Activity Monitor → OpenTouch Helper (Renderer) → Force Quit) → окно перезапускается, проект из автосохранения.

## Производительность
- [ ] 10 поверхностей + 2 видео 1080p: в DevTools (⌥⌘I) → Performance — 60 fps на выводе; `document.querySelector('video').getVideoPlaybackQuality().droppedVideoFrames` растёт не больше чем на 5 за 10 с.
